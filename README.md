# Restaurant Analytics Project

## Project Overview
An end-to-end Restaurant Analytics project focused on analyzing sales performance, customer behavior, customer feedback, and inventory variance using Python, MySQL, and Power BI.

The objective is to transform raw restaurant business data into meaningful insights and actionable business recommendations.

## Business Objectives
- Analyze overall sales and revenue performance.
- Evaluate order trends across sales channels.
- Identify top-performing stores and products.
- Understand customer purchasing frequency.
- Analyze customer feedback and ratings.
- Examine inventory stock variance.

## Tools & Technologies
- Python (Pandas, NumPy)
- MySQL
- Power BI
- Microsoft Excel

## Dataset Overview
The project uses a synthetic restaurant dataset covering 2025 business operations.

| Table | Records |
|---|---:|
| Stores | 30 |
| Products | 50 |
| Customers | 20,000 |
| Orders | 40,000 |
| Order Items | 100,000 |
| Daily Inventory | 12,000 |
| Customer Feedback | 8,001 |
| Complaints | 2,000 |
| **Total** | **182,081** |

## Key Business Metrics
- Total Revenue: ₹26.77 Million
- Completed Orders: 36,798
- Average Order Value: ₹727.50

## Analysis Areas
1. Sales Performance Analysis
2. Store and Product Performance
3. Customer Analytics
4. Customer Feedback and Ratings
5. Inventory Stock Variance Analysis

## Key Insights
- May recorded the highest monthly sales.
- February recorded the lowest monthly sales.
- Dine-in was the highest revenue-generating sales channel.
- East region recorded the highest regional revenue.
- Peri Peri Chicken Pizza was the top-selling product by quantity.
